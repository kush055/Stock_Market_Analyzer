# 📈 Basic Stock Price Alert System

A simple Python-based stock monitoring tool that tracks real-time stock prices and gives a **prompt/alert** when a stock hits a specified target price. Ideal for beginners looking to automate basic stock tracking tasks.

---

## 🔧 Features

- 🔍 Track live stock prices (via Yahoo Finance).
- ⏰ Get a prompt when the stock hits or crosses a set threshold.
- 💻 Simple terminal-based interface.
- 📝 Easy to configure stock symbol and target price.

---

## 🛠️ Tech Stack

- **Language**: Python 3
- **Library Used**: 
  - [`yfinance`](https://pypi.org/project/yfinance/)
  - `time`
  - `os` or `winsound` (optional, for audio alerts)
